# Unified Live Website Build Package

This package contains the source Markdown files an AI website builder or design agent needs to create the complete Unified Live website.

## How to use

1. Read `brand.md`, `services.md`, `industries.md`, `about.md`, `locations.md`, and `contact.md` before generating any page.
2. Use `site-map.md` for the required information architecture.
3. Use `design-brief.md` for visual, accessibility, and responsive-design requirements.
4. Use `seo.md` for metadata, page titles, and search optimization.
5. Use `ai-agent-content.md` as the structured, machine-readable content source for the AI Agent View.
6. Use `faqs.md` for the FAQ page and optional FAQ schema.
7. Place any supplied logo, favicon, or imagery in `assets/`.

## Build rules

- Build for humans first, but expose the same core content in structured Markdown for AI agents.
- Do not invent clients, testimonials, certifications, statistics, pricing, product names, vendor partnerships, or case studies.
- Do not feature specific products or vendor SKUs in the initial website.
- Treat audiovisual integration and video conferencing as equally important to live streaming and broadcast.
- Keep all claims factual, service-led, and outcome-oriented.
